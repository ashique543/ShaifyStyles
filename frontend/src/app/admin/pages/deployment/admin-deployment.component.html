Step 1

Deploy Python Flask API to Render or Railway

The backend is pre-configured with a production Procfile and gunicorn server.

1
Connect GitHub Repository

Go to Render Dashboard > Click New + > Web Service > Select your repository ashique543/ShaifyStyles.

2
Set Service Settings
Root Directory: backend
Runtime: Python 3
Build Command: pip install -r requirements.txt
Start Command: gunicorn -w 4 -b 0.0.0.0:$PORT "run:app"
3
Create Admin User on Production

From the Render/Railway shell terminal, run the seed command to create your live store admin:

flask create-admin --username admin --email owner@shaifystyles.com
Step 2

Deploy Angular Frontend to Vercel or Netlify

Vercel and Netlify offer ultra-fast global CDN delivery with zero-downtime deploys. SPA routing rewrites are pre-packaged in frontend/vercel.json and frontend/public/_redirects.

1
Deploy with Vercel (Recommended)

Log in at Vercel.com > Add New... > Project > Import ashique543/ShaifyStyles.

Root Directory: frontend
Framework Preset: Angular
Build Command: npm run build
Output Directory: dist/frontend/browser
2
Connect Frontend to Live Backend API

In Vercel Project Settings > Environment Variables, add:

API_URL=https://shaify-styles-api.onrender.com/api
Step 3

Provision Free PostgreSQL Database

For high-performance order tracking and concurrent customers, connect a managed PostgreSQL instance.

1
Choose a Free PostgreSQL Provider:
  • Render Postgres: Click New + > PostgreSQL in Render.
  • Neon.tech: Instant serverless PostgreSQL (neon.tech).
  • Supabase: Free managed PostgreSQL (supabase.com).
2
Set DATABASE_URL in Backend Environment

Copy the connection string (starting with postgresql://...) into your backend service environment variables:

DATABASE_URL=postgresql://user:password@ep-lucky-pool.neon.tech/shaifystyles?sslmode=require
Note: SQLAlchemy automatically detects PostgreSQL and provisions all tables (`products`, `orders`, `order_items`, `users`, `otp_store`, `admins`) on startup!
Step 4

Setup Customer Google Login & SMS OTP

🌐 Google Sign-In Setup

  1. Visit Google Cloud Console > Create a project Shaify Styles.
  2. Go to APIs & Services > Credentials > Create Credentials > OAuth client ID.
  3. Application type: Web application.
  4. Add your frontend URL under Authorized JavaScript origins:
    https://shaifystyles.vercel.app
  5. Copy the generated Client ID and add it to your GOOGLE_CLIENT_ID variable.

📱 Fast2SMS or Twilio OTP Setup

  1. Sign up at Fast2SMS.com (India DLT/Quick OTP) or Twilio.
  2. Copy your Fast2SMS API key from your dashboard.
  3. Set the environment variables in your backend:
    SMS_GATEWAY=fast2sms
    FAST2SMS_API_KEY=your_live_api_key_here
  4. When left unset, the store operates in Simulation Mode (OTP code 123456 is displayed directly on the screen and in terminal logs).
